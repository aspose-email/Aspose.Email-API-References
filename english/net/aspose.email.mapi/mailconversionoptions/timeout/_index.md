## MailConversionOptions.Timeout property

Gets or sets the time limit, in milliseconds, for formatting the message body during the conversion. The default is 3000 (3 seconds).

```csharp
public int Timeout { get; set; }
```

## Remarks

When the limit is reached, [`TimeoutReached`](../timeoutreached/) is raised.
