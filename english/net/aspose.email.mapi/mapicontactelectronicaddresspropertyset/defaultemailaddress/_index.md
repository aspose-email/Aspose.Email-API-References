## MapiContactElectronicAddressPropertySet.DefaultEmailAddress property

Gets or sets the address used as [`Email1`](../email1/) when the contact has no address and [`UseAutocomplete`](../useautocomplete/) is `true`.

```csharp
public MapiContactElectronicAddress DefaultEmailAddress { get; set; }
```

## Remarks

Exchange Server needs an address to create a contact; this one is used when a contact without addresses is created through EWS.
