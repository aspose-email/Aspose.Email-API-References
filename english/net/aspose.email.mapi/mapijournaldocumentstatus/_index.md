## MapiJournalDocumentStatus enumeration

Defines what happened to a document during a journaled activity. The values can be combined.

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | `0` | Nothing happened to the document. |
| Printed | `1` | The document was printed. |
| Saved | `2` | The document was saved. |
| Routed | `4` | The document was sent to a routing recipient. |
