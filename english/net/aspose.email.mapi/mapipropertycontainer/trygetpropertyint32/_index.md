## MapiPropertyContainer.TryGetPropertyInt32 method

Gets the value of a property as a 32-bit integer, if the property exists.

```csharp
public bool TryGetPropertyInt32(long tag, ref int value)
```

| Parameter | Type | Description |
| --- | --- | --- |
| tag | Int64 | The tag of the property. |
| value | Int32& | When this method returns, the value of the property, if it exists; otherwise, the value is unchanged. |

### Return Value

`true` if the property exists; otherwise, `false`.
