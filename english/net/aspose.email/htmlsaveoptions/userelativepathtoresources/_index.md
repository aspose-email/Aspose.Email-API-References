## HtmlSaveOptions.UseRelativePathToResources property

Gets or sets a value indicating whether the HTML refers to resources saved to files by relative paths instead of absolute ones. The default is `false`.

```csharp
public bool UseRelativePathToResources { get; set; }
```

## Remarks

Used with `ResourceRenderingMode.SaveToFile`: the resources are saved to a folder named after the HTML file with `_files` appended.
