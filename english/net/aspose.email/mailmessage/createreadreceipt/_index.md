## MailMessage.CreateReadReceipt method

Creates a read receipt for the message.

```csharp

```

| Parameter | Type | Description |
| --- | --- | --- |
| from | String | The address of the sender of the receipt. |
| bodyText | String | The text of the receipt; `null` or empty for the default text. |
