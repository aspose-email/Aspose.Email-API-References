## MailMessage.RecomposeTnefContent method

Rebuilds the TNEF attachment (winmail.dat) of a message that was loaded from TNEF, so that it reflects the changes made to the message.

```csharp
public void RecomposeTnefContent()
```

## Remarks

It applies only to a message that originally contained TNEF and was loaded without `FileCompatibilityMode.PreserveTnefAttachments`; it does not turn an ordinary message into TNEF.
