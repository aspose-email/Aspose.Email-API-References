## AttachmentPermissionType enumeration

Defines who can view or edit the file of a cloud (reference) attachment.

```csharp
public enum AttachmentPermissionType
```

### Values

| Name | Value | Description |
| --- | --- | --- |
| None | `0` | The file is not shared. |
| RecipientsCanView | `1` | The recipients can view the file. |
| RecipientsCanEdit | `2` | The recipients can edit the file. |
| AnyoneCanView | `3` | Anyone with the link can view the file. |
| AnyoneCanEdit | `4` | Anyone with the link can edit the file. |
| OrganizationCanView | `5` | Users in the same organization can view the file. |
| OrganizationCanEdit | `6` | Users in the same organization can edit the file. |
