## CalendarReader.LoadAsMultiple method

Reads all events of the calendar.

```csharp
public List<Appointment> LoadAsMultiple()
```

### Return Value

The events, in the order they appear in the calendar.

## Remarks

Reading starts from the first event regardless of `AppointmentLoadOptions.EventIndex`, and the position used by `NextEvent` does not change.
