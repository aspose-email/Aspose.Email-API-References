## AppointmentFormattingOptions.EndDateFormat property

Gets or sets the template for the end date and time.

```csharp
public string EndDateFormat { get; set; }
```

### Property Value

A composite format string in which `{0}` is replaced by the end date and time. The plain-text default is `EndTime: {0}`.
