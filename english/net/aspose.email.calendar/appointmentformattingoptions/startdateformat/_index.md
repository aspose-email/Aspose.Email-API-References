## AppointmentFormattingOptions.StartDateFormat property

Gets or sets the template for the start date and time.

```csharp
public string StartDateFormat { get; set; }
```

### Property Value

A composite format string in which `{0}` is replaced by the start date and time. The plain-text default is `StartTime: {0}`.
