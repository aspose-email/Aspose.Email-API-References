## AppointmentFormattingOptions.TitleFormat property

Gets or sets the template for the title (the summary of the appointment).

```csharp
public string TitleFormat { get; set; }
```

### Property Value

A composite format string in which `{0}` is replaced by the title. The plain-text default is `Title: {0}`.
