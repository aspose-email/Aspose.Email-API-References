A postal address of a contact: street, city, state or province, postal code and country.

Use this class to manage physical addresses in [MapiContact](../../com.aspose.email/mapicontact) items. The class supports multiple address types (home, work, other) and includes properties like \#getStreet().getStreet(), \#getCity().getCity(), \#getStateOrProvince().getStateOrProvince(), \#getPostalCode().getPostalCode(), \#getCountry().getCountry(), and \#isMailingAddress().isMailingAddress() to fully define a physical address.
