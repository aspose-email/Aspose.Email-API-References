## EmptyFolderOptions enumeration (3 values)

Enumerates the empty folder options

| Value | Description |
| --- | --- |
| None | If DeletePermanently flag is not set, move folder contents excluding subfolders to DeletedItems folder. |
| DeleteSubfolders | Include subfolders into deletion operation. |
| DeletePermanently | Indicates that items should be deleted permanently. |
