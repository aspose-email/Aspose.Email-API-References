## MessageTrackingReportTemplate enumeration (2 values)

Enumerates the types of report to display.

| Value | Description |
| --- | --- |
| Summary | Specifies that the report will display all the recipients of the message and the delivery status of the message to each recipient. |
| RecipientPath | Specifies that for a single recipient, the report will display a full history of the events that occurred. |
