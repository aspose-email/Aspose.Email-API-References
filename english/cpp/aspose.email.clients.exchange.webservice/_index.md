## Aspose::Email::Clients::Exchange::WebService namespace

The Aspose::Email::Clients::Exchange::WebService namespace groups the core types used to communicate with Exchange Web Services (EWS). It includes clients, data models for calendar events, conversations, and options for managing deletions and date ranges.
