## WellknownTaskListName enumeration (3 values)

Property indicating the list name if the given list is a well-known list. Possible values are: none, defaultList, flaggedEmails, unknownFutureValue.

| Value | Description |
| --- | --- |
| none | User created list. |
| defaultList | Built-in Tasks list. |
| flaggedEmails | Built-in Flagged email list. Tasks from flagged emails are present in this list. |
