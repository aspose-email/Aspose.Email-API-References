## Aspose::Email::Clients::Graph namespace

The Aspose::Email::Clients::Graph namespace groups the core objects—such as BaseRestObject, Bucket, CalendarInfo, FolderInfo, and ClassificationOverride—used to model Graph entities, and includes GraphClient for authentication and request execution. Use these classes to build, query, and manage email and calendar data through the Microsoft Graph API.
