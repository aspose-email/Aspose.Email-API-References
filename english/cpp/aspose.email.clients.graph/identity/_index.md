## Identity class

https://docs.microsoft.com/en-us/graph/api/resources/identity?view=graph-rest-1.0 The Identity resource represents an identity of an actor. For example, an actor can be a user, device, or application.

## Methods

| Name | Description |
| --- | --- |
| [get_DisplayName](./get_displayname/) | The identity's display name. Note that this may not always be available or up to date. For example, if a user changes their display name, the API may show the new value in a future response, but the items associated with the user won't show up as having changed when using delta. |
| [get_Id](./get_id/) | Unique identifier for the identity. |
| [get_Thumbnails](./get_thumbnails/) | The ThumbnailSet resource is a keyed collection of thumbnail resources. |
