## CalendarDay enumeration (11 values)

| Tuesday | Tuesday. |
| Wednesday | Wednesday. |
| Thursday | Thursday. |
| Friday | Friday. |
| Saturday | Saturday. |
| Sunday | Sunday. |
| Day | Represents all days of the week: SU,MO,TU,WE,TH,FR,SA. |
| WeekDay | Represents weekdays of the week: MO,TU,WE,TH,FR. |
