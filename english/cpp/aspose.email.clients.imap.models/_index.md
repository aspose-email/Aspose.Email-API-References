## Aspose::Email::Clients::Imap::Models namespace

The Aspose::Email::Clients::Imap::Models namespace defines the data structures used by the IMAP client to represent message sets, operation parameters, and result types. These models enable developers to construct, execute, and interpret IMAP commands such as fetching messages, changing flags, copying, moving, and deleting messages.
