## Aspose::Email::Common::Delegate namespace

The Aspose::Email::Common::Delegate namespace groups the delegate definitions used throughout the Aspose.Email library to enable custom processing of email items, such as callbacks for item creation, modification, or deletion. It includes classes like ItemCallbackArgs that encapsulate event data passed to user‑defined handlers.
