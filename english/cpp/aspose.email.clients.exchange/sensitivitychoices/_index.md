## SensitivityChoices enumeration (5 values)

Enumerates the sensitivity level types that are available for an item.

| Value | Description |
| --- | --- |
| Undefined | Sensitivity level is not specified |
| Normal | Specifies the item as normal. |
| Personal | Specifies the item as personal. |
| Private | Specifies the item as private. |
| Confidential | Specifies the item as confidential. |
