## MessageInfoType enumeration (6 values)

Enumerates the message types.

| Value | Description |
| --- | --- |
| None | Undefined type. |
| MailMessage | This value represents the E-mail messages type (IPM.Note class ID). |
| Appointment | This value represents the Appointments type (IPM.Appointment class ID). |
| Task | This value represents the Tasks type (IPM.Task class ID). |
| Post | This value represents the Posting notes type (IPM.Post class ID). |
| Contact | This value represents the Contacts type (IPM.Contact class ID). |
