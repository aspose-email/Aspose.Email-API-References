## MapiTaskOwnership enumeration (3 values)

Indicates the role of the current user relative to the Task object.

| Value | Description |
| --- | --- |
| NotAssigned | The Task object is not assigned. |
| AssignersCopy | The Task object is the task assigner's copy of the Task object. |
| AssigneesCopy | The Task object is the task assignee's copy of the Task object. |
