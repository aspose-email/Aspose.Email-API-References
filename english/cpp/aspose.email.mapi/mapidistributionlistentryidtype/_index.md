## MapiDistributionListEntryIdType enumeration (5 values)

Specifies the type of EntryID.

| Value | Description |
| --- | --- |
| OneOff | Designates a one-off EntryID. The EntryID must be a One-Off EntryID structure. |
| Contact | EntryID of a Contact object. The EntryID must be a Message EntryID structure. |
| DistributionList | EntryID of a Personal Distribution List object. The EntryID must be a Message EntryID structure. |
| GalMailUser | EntryID of a mail user in the GAL. The EntryID must be an Address Book EntryID structure. |
| GalDistributionList | EntryID of a distribution list in the GAL. The EntryID must be an Address Book EntryID structure. |
