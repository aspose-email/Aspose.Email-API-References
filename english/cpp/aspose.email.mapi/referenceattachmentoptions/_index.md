## ReferenceAttachmentOptions class

Represents configuration options for adding a reference attachment to a MAPI message.

## Constructors

| Name | Description |
| --- | --- |
| [ReferenceAttachmentOptions](./referenceattachmentoptions/) | Initializes a new instance of the ReferenceAttachmentOptions class with the specified shared link, URL, and provider name. |
