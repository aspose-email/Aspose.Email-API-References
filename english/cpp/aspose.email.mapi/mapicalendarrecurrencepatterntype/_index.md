## MapiCalendarRecurrencePatternType enumeration (8 values)

Enumerates the mapi calendar recurrence pattern types

| Value | Description |
| --- | --- |
| Day | The event has a daily recurrence. |
| Week | The event has a weekly recurrence. |
| Month | The event has a monthly recurrence. |
| MonthEnd | The event has a month-end recurrence. |
| MonthNth | The event has an every nth month pattern. |
| HjMonth | The event has a monthly recurrence in the Hijri calendar |
| HjMonthNth | The event has an every nth month pattern in the Hijri calendar. |
| HjMonthEnd | The event has a month end recurrence in the Hijri calendar. |
