## FormTarget enumeration (3 values)

Indicates where to display the form response after submitting the form. The value must be _blank or _top.

| Value | Description |
| --- | --- |
| Undefined | Undefined. |
| Blank | Display in new window. |
| Top | Displays on top of window. |
