## RestoreOptions enumeration (4 values)

Enumerates restore options

| Value | Description |
| --- | --- |
| None | Indicates that no specific options are specified |
| Recursive | Indicates that nested folders should be also restored |
| RemoveNonexistentFolders | Indicates that mail folders, which do not have the equal folders in the personal storage, should be removed |
| RemoveNonexistentItems | Indicates that mail items, which do not have the equal items in the personal storage, should be removed |
