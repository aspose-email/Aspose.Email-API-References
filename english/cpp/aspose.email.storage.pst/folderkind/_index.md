## FolderKind enumeration (2 values)

Represents the different kinds of pst folders.

| Value | Description |
| --- | --- |
| Normal | Represents the normal pst folder. |
| Search | Represents the search folder. It is a virtual folder that provides a view of all email items that match specific search criteria. |
