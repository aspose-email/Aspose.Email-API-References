## Aspose::Email::Clients::Pop3::Models namespace

The Aspose::Email::Clients::Pop3::Models namespace defines the data structures used by the POP3 client for retrieving message metadata and persisting messages. It includes classes such as Pop3LoadMessageInfoList for fetching message summaries and Pop3SaveMessage for storing complete messages to a POP3 server.
