## AppointmentStatus enumeration (4 values)

Defines the overall status or confirmation for the appointment.

| Value | Description |
| --- | --- |
| NotDefined | Value is not defined |
| Cancelled | Indicates journal is removed. or Indicates to-do was cancelled. or Indicates event was cancelled. |
| Tentative | Indicates event is tentative. |
| Confirmed | Indicates event is definite. |
